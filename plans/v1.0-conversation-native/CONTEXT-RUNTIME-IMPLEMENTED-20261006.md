# 上下文改造：本地实现与验收

本轮按 ADR-003 实施来源明确的目标/决定记录、当前任务事实恢复、上下文快照与差异、历史证据范围读取、独立摘要预算和分段恢复。通用字段、来源与生命周期属于产品层；当前完整序列化/摘要执行已接到本地CLI适配器，其他服务仍需接入相同接口并实测。没有变更训练质量门、数据划分、原模型或执行批准机制。

## 已实现

| 组件 | 行为 | 验证 |
|---|---|---|
| ContextStateStore | 用户消息自动保存；Agent解释用原话、请求ID和caller绑定；保留不可变版本、替代关系与重放幂等性 | 旧消息不能覆盖新选择、提案不能覆盖用户选择、系统通知不能变成用户决定；会话记录不能产生执行权限 |
| 当前目标恢复 | 读取当前Task业务目标、固定Spec版本及user_note，保留预算和仅准备/不训练等条件 | 修复原始task.json不含扩展task_spec时目标为空的问题；读取不经过运行时/DSH RPC锁 |
| 历史证据读取 | 按消息ID或已冻结提案的声明文件取回指定字符范围；返回摘要、范围与完整性 | 不接受宿主文件路径；源码片段以UTF-8摘要校验，避免脱敏改变原代码 |
| ContextSnapshot/Diff | 记录实际模型可见system、history、tools与continuation，父版本、内容变化及预算/排除记录 | 文件私有、不可覆盖且可校验；不记录模型隐藏推理或传输凭据；不导出到模型包 |
| 独立预算 | 普通输入750KB、摘要输入300KB、可见输出64KB；最多8个摘要片段与120秒总摘要窗口 | 这些是本地字节工作预算；Token计数是显式标注的估计，不能称为真实Tokenizer或费用上限 |
| 分段摘要 | 按完整工具调用/结果组切分，只读、无执行工具；保存成功片段并按来源/策略/模型校验后复用 | 不完整配对、单个必需组超限、超出片段数、工具意图、坏摘要或输出超限均失败关闭 |

原始记录保留在窗口外；摘要只帮助导航。TaskSpec、Dataset、合同、Run、评估和一次性批准仍是确定性事实源。源码和片段不参与投影后的原始合同/代码摘要重算。

## 页面复验

批次：`runs/acceptance/20261006-context-runtime/`。训练与效果验收是另一层，本批次没有创建新训练Run。

正常用户案例使用模糊的“看看店里卖得怎么样、怎么备货”，随后明确“全店下周每日总销量、不按商品、仅整理数据、不训练、预算以后确认”。后续回复直接给数据整理步骤；用户明确要求记住后，真实保存4项带原文引用的选择，刷新恢复仍可读取。完整页面捕获与独立评审分别保留，不以接口或单元测试代替页面观察。

页面测试同时发现侧栏折叠后隐藏按钮仍暴露在可访问树，测试器点击“开始新任务”未生效、误发入旧对话。原任务的规范和模型Run已核对未改变。保留失败批次 `navigation-failure-before-fix`；修复inert/aria-hidden和测试器先打开可见任务列表、等待首页后发送，另开新批次重跑，不改旧记录为通过。

## 工具与入口

- `model_harness_get_context_state` / `model_harness_record_context_state`：当前所属对话的来源记录与解释。
- `model_harness_read_context_evidence`：回查消息或冻结源码片段。
- `model_harness_inspect_context`：当前根会话的快照、预算、已装载内容与差异。
- 私有持久记录位于runs工作区的 `context-state`、`context-snapshots`、`context-traces`、`context-summary-fragments`，全部留在Git忽略的本地运行区。

## 后续边界

收尾验证：Python完整回归915项、Node完整回归451项通过；五轮自然对话（包含实际保存4项选择和刷新续接）的独立评审与逐字引用检查通过；原语音长对话读取成功，质量失败、原模型/Run与只读要求保留。约398,601字节的合成历史通过真实模型分成两段处理；该压力试验是辅助模型调用，不是页面训练验收。

压力试验发现并保留两类摘要问题：推断出未选择过的旧方案、将宿主摘要/传输指令当作用户目标。当前策略版本working-set-v2将宿主摘要指令与真实用户消息分角色处理，并只向工作集提供可匹配原始来源的引用、来源角色和附近上下文；未验证的解释保留在私有片段记录中，不作为当前事实、用户选择或授权。原失败摘要、改进记录与最终来源复核分别归档。

本轮不声称所有供应商已实测、不声称语义引用校验能证明解释正确。需继续做长历史位置/噪声/缺证据对照、跨模型实测、专家交接瘦身和工具Schema按需装载。时序试用的57天过期预测输入仍是模型数据上下文问题；聊天上下文修复不会消除该限制。原语音/OCR质量失败和工单否定语义错误仍须作为业务质量问题处理，不能以这轮工程验收通过覆盖它们。
