# Warm Editorial Workbench 视觉系统

> 状态：2026-08-26 已进入实现
> 参考：WorkBuddy 模型训练过程、已确认的 Conversation Native 交互方案
> 原则：学习其克制、连续的对话体验，不复制其任务真相缺陷

## 1. 产品视觉目标

Specialist Model Studio 是模型训练智能工作台，不是营销首页，也不是训练后台。
第一屏必须让用户自然地表达目标；有任务后，对话是主线，Workspace 只承接需要
阅读、比较或验收的对象。

视觉方向命名为 **Warm Editorial Workbench**：

- 暖中性页面与白色文档面占主要面积；
- 品牌紫只用于发送、确认、焦点和训练协调器身份；
- 状态颜色只表达生命周期，不承担装饰；
- 普通 Agent 回复不套卡，执行过程只有一个折叠组；
- HumanCheckpoint 是当前页面唯一高强调对象；
- 结果在对话中给结论，在 Workspace 中以文档方式展开。

## 2. 布局契约

| 区域 | 桌面规格 | 窄屏规格 |
| --- | --- | --- |
| 任务栏 | 248px，暖灰背景 | 抽屉；移动端全宽 |
| 顶栏 | 56px，单行标题与唯一权威状态 | 52px，状态换到标题下方 |
| 对话阅读宽 | 860px 上限 | 左右 12px 安全边距 |
| Workspace | 400–520px 文档面 | 全屏 Sheet |
| Composer | 与对话同宽，16px 圆角 | sticky，保留 44px 操作目标 |

桌面验证：1440×900、1280×800。移动验证：390×844。

## 3. 基础令牌

- 字体：macOS 原生 SF / PingFang 优先；仅使用 400、500、600、700。
- 正文：15px / 24px；组件正文：14px / 22px；辅助信息最低 12px / 18px。
- 间距：4、8、12、16、20、24、32、40、48。
- 圆角：6、10、16、pill 四级。
- 阴影：仅 Composer、Drawer、Dialog 使用。
- 中性色：暖白、暖灰、深石墨；品牌紫占比小于 5%。
- 运行 / 成功 / 等待 / 失败：蓝 / 绿 / 琥珀 / 红，互不混用。

完整 token 由 `model_harness/web/visual-system.css` 维护。旧样式只作为深层
训练面板的兼容基线，新组件不得再向 `styles.css` 追加版本型覆盖块。

## 4. 核心组件契约

| 组件 | 视觉与交互契约 |
| --- | --- |
| 用户消息 | 中性灰气泡；最大宽 76%；正文 15/24 |
| Agent 消息 | 无外框；头像、角色、正文形成一条连续阅读线 |
| 执行过程 | 一层 disclosure；内部为发丝线动作行，不重复团队卡 |
| HumanCheckpoint | 白底、左侧品牌强调线、16px 内边距；长选项单列 |
| 状态 Chip | 24–26px；12px/600；只显示一个权威状态 |
| 主按钮 | 40px，8px 圆角；同一上下文只保留一个主按钮 |
| 图标按钮 | 桌面 36px，移动 44px |
| Composer | 最小 112px；16px 圆角；白底轻浮层阴影 |
| Workspace | 单一文档面；section 之间用分隔线，不用卡片套卡片 |
| 结果 | 对话显示 verdict；完整指标、lineage 和产物进入 Workspace |

## 5. 本轮实施范围

### P0

- 新增统一 token 与核心组件样式；
- 首页去营销化，让 Composer 成为第一视觉焦点；
- 收敛 Sidebar、Topbar、消息、状态、Composer；
- 有 paired actions 时不再重复渲染 `team-activity`；
- 扁平化 Action、HumanCheckpoint 和 Workspace；
- 修正不可点击 Run 结果行的 pointer 暗示；
- 桌面与移动真实浏览器检查。

### 后续清理

- 将深层训练详情逐模块迁移出历史 `styles.css`；
- 删除迁移完成的重复 selector、裸色值和非标准字重；
- 为首页、澄清、确认、执行、结果、失败、断连建立视觉快照门。

## 6. 验收门

- 主页面没有卡片套卡片造成的三层边框；
- 当前人工决定在一屏内可识别、可操作；
- 普通信息不使用紫色底；
- 桌面和移动无横向溢出、遮挡和小于 44px 的关键触控目标；
- Console 无 error；
- 视觉检查与功能测试分别通过，不能互相替代。
