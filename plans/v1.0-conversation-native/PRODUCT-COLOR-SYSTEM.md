# Specialist Model Studio · 产品色系规范

## 1. 色彩原则

- 品牌色只用于焦点、关键确认和被选中对象，不用于大面积铺底。
- 中性色承担主要界面层级，避免“每个状态都是紫色”。
- 运行、成功、等待、失败、取消各有唯一语义色；颜色不能替代文字标签。
- 所有正文与交互文字在对应背景上至少满足 WCAG AA 对比度。

## 2. 核心色板

| Token | 色值 | 用途 |
| --- | --- | --- |
| `brand` | `#5A4FD6` | 焦点、关键确认、选中态 |
| `brand-hover` | `#493FBE` | 品牌按钮 hover |
| `brand-active` | `#3E35A7` | 品牌按钮 pressed |
| `brand-soft` | `#F0EEFC` | 低权重选中背景 |
| `text-primary` | `#242329` | 标题、主信息、主操作 |
| `text-secondary` | `#5E5B66` | 正文、解释 |
| `text-tertiary` | `#726E79` | 时间、辅助元数据；在白色与暖白表面保持 AA 对比度 |
| `canvas` | `#F5F5F2` | 应用画布 |
| `surface` | `#FFFFFF` | 对话、文档、输入区 |
| `surface-muted` | `#F0F0EB` | hover、低权重分区 |
| `border` | `#E5E3DC` | 普通分隔线 |
| `border-strong` | `#D2CFC5` | 输入和交互边界 |

## 3. 状态色

| 状态 | 主色 | 浅色背景 | 使用边界 |
| --- | --- | --- | --- |
| 运行 | `#496B9F` | `#EDF2F9` | 真实 active Action / Run |
| 成功 | `#1F7A58` | `#EDF7F2` | 已验证完成、通过门槛 |
| 等待 | `#8F5E22` | `#FBF3E6` | 等待用户、资源或外部条件；小字号文字保持 AA 对比度 |
| 失败 | `#B34F52` | `#FBEFEF` | 工具失败、证据冲突、阻断 |
| 取消 | `#6D6A75` | `#F1F0F2` | 用户停止或终止状态 |

## 4. 组件使用规则

- 首页与对话正文以暖白、中性灰为主；品牌紫不超过首屏视觉面积的 8%。
- 主确认按钮使用品牌紫；危险操作使用失败红；普通导航和“新建任务”使用白底描边。
- HumanCheckpoint 是当前唯一高权重卡片，使用 3px 品牌色左边框。
- Action 时间线只在真实运行时使用运行蓝；历史完成项回归中性色和小面积成功绿。
- `running / loading / active Action` 统一使用运行蓝，不能借用品牌紫或成功绿；成功绿只代表已经被证据验证的完成状态。
- `cancelled / interrupted` 使用取消灰；只有 `failed / blocker / evidence conflict` 使用失败红。`cancelling` 在请求尚未生效时必须配文字说明，最终状态仍回到取消灰。
- Workspace 报告采用文档式白底，评测结论使用状态色，不使用彩色大卡片。
- disabled 状态统一降低对比度，不改变成另一个语义色。
- Focus、hover 与选中态必须引用 `brand / brand-soft / focus-ring`，禁止在组件中继续写旧版 `#6258F4` 或 `rgba(98, 88, 244, …)`。

## 5. 品牌标记

生成概念采用“两条协作路径汇聚到一个专业模型核心”的结构。生产版使用纯平面 SVG：紫色代表 AI 协调路径，温黑代表工程执行路径，翡翠色方块代表最终形成的 specialist model。禁止重新加入 `H/HU` 字母、纸飞机、机器人脸、神经网络圆点或渐变。
