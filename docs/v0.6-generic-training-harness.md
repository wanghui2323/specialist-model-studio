# v0.6 通用模型训练 Harness

## 产品合同

Model Harness接收的不是“某一个图片分类表单”，而是一项持续存在的 `Training Task`：用户描述业务目标，系统把它规范成 `Capability Request`，再匹配已安装的 `Recipe` 与 `Data Adapter`。同一个任务承载数据版本、冻结合同、人工确认、运行事件、指标、错误样本、制品和优化子运行。

两个真实场景只是首轮验收下限。产品对新场景的承诺是“能够进入同一条可审计流程并最终扩展跑通”，不是“当前仓库已经实现所有算法”。

```text
Training Task
  ├─ Capability Request
  ├─ Recipe + Data Adapter（已匹配）
  │    └─ Dataset → Contract → Approval → Run → Evaluation → Artifacts
  └─ Recipe Build Request（未匹配）
       └─ Scaffold → Code Agent实现 → 隔离验证 → 插件注册 → 回到同一任务
```

## 核心对象与唯一事实源

| 对象 | 唯一ID | 事实归属 | 完成条件 |
| --- | --- | --- | --- |
| Training Task | `task_id` | `runs/_workspace/tasks/<task_id>/task.json` | 当前状态可从磁盘恢复 |
| Capability Request | `task_id`内嵌 | Task | 模态、目标、输出类型、约束已规范化 |
| Recipe Build Request | `recipe_request_id` | Task工作区 | 插件完成实现、验证与注册 |
| Dataset | `dataset_id` | Task工作区 | Adapter报告与不可变指纹写入 |
| Contract | `task_id` | Task工作区 | 三项人工确认后冻结 |
| Run | `run_id` | `runs/<run_id>` | 终态、事件、指标与制品一致 |
| Artifact | `run_id + name` | Run目录 | 哈希匹配，深度验证可重放 |

前端、DeepSeek Harness和脚本都只能读写这些后端对象，不拥有第二套任务状态。

## 当前可直接执行的能力

### 图片多分类

- Data Adapter：`image-folder-zip`
- Recipe：`image-folder-classification`
- 输入：`类别/图片.jpg` 结构ZIP
- 训练：基线、Logistic Regression、线性hinge SGD与Random Forest候选比较
- 独立评测：Accuracy、Macro-F1、最差类别Recall、延迟、模型体积

### CSV数值回归

- Data Adapter：`tabular-csv`
- Recipe：`tabular-regression`
- 输入：UTF-8 CSV与明确的目标字段，可声明忽略字段和分隔符
- 训练：均值基线、Ridge、Random Forest与Extra Trees候选比较
- 独立评测：MAE、RMSE、R²、延迟、模型体积

## 未支持场景如何进入系统

例如用户提出音频关键词识别。能力匹配没有可执行Recipe时：

1. 创建真实Training Task，状态为 `needs_recipe`；
2. 持久化Recipe Build Request，不创建Run、不显示训练进度；
3. 用户批准后生成Code Agent构建包；
4. 构建包提供Recipe/Data Adapter协议骨架、entry point声明、成功与无效数据测试骨架；
5. 人或Code Agent补齐算法、模型来源、数据校验、指标、制品与依赖许可；
6. 在隔离环境完成正反测试和深度验证，安装插件；
7. 将验证过的Recipe选回原task，继续数据、合同、训练与评测流程。

当前版本只完成1–4以及外部entry point注册协议。它不会自动执行LLM生成代码，也没有隔离构建环境；因此不能把“脚手架已生成”称为“任意模型已经可训练”。

## 真实验收

执行：

```bash
.venv/bin/python scripts/run_real_scenarios.py
```

2026-08-21的本地验证结果：

| 场景 | 数据 | Recipe | 独立测试结果 | 产物验证 |
| --- | --- | --- | --- | --- |
| 手写数字图片分类 | scikit-learn/UCI Digits，1,797张，10类 | `image-folder-classification` | Accuracy 0.9833；Macro-F1 0.9833；最差类Recall 0.9444 | 10项产物，深度验证通过 |
| 葡萄酒质量回归 | UCI Wine Quality红酒CSV，原始1,599行，去重1,359行，11特征 | `tabular-regression` | MAE 0.4683；RMSE 0.5990；R² 0.3971 | 10项产物，深度验证通过 |

两条链路都额外验证：合同未确认时启动返回409且不改变run列表；进程重新打开task后仍能恢复当前结果；后端事件序列、产物清单和深度验证一致。

## 前端与DeepSeek Harness边界

`/app`是正式产品界面：左侧Training Task，中间对话与五步计划，右侧能力/数据/运行/评测/产物上下文。没有DeepSeek Harness时，用户仍可创建任务、导入数据、确认合同、显式批准启动训练、查看真实事件并下载产物。

DeepSeek Harness通过插件提供可选的Agent Loop、18个领域工具和原生审批。它不是本项目的fork，不保存训练事实，也不会替代后端状态校验。
